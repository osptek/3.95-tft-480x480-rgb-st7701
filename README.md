# 3.95 寸 480×480 TFT RGB 模组（ST7701）资料与示例

**English：** [`README_EN.md`](README_EN.md)

---

> 本仓库提供该模组的 **ESP-IDF 示例工程**（RGB + LVGL9）。数据手册与规格书待后续补充至 `docs/`。

## 产品概要

| 项目 | 说明 |
|:--|:--|
| 模组规格 | 3.95 英寸 **TFT**，分辨率 **480×480** |
| 接口 | **RGB**（16-bit，经 3-wire SPI 下发初始化） |
| 驱动芯片 | **ST7701** |
| 规格标识 | 产品资料中常用 **`3.95-tft-480x480-rgb-st7701`** 表示本规格 |
| 与 MIPI 版关系 | 同尺寸 **ST7102 MIPI** 见仓库 **`3.95-tft-480x480-mipi-st7102`**，接口不同、独立维护 |
